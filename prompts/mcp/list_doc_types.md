---
tool: list_doc_types
---

List all document types. Each entry has `doc_type_id`, `name`, `description`,
`document_count` and `emoji`.

The `emoji` is a **visual illustration only** — it is NOT part of the name and must NOT
be used in searches or identifiers. When presenting doc-types, display the emoji before
the name (e.g. `📄 invoice`). If `emoji` is null, omit it.

Use this before creating a new doc-type so you can reuse an existing one.
